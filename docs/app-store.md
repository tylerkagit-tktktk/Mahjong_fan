# App Store Copy

## App Name
麻雀番埋嚟

## Subtitle
記錄對局．整理結果．快速分享

## Description
麻雀番埋嚟是一個本機優先的麻雀對局記錄與計分工具。你可以快速開局、逐手記錄、結束後查看總結，並以可讀格式分享結果。需要同枱同步時，可選擇建立多人房間並以邀請連結讓其他裝置加入。

### 核心功能
- 對局管理：開新局、進行中追蹤、結束後只讀摘要。
- 手數記錄：每手結果與局風進度顯示。
- 歷史列表：按時間篩選與分組查看。
- 分享摘要：玩家排名、食糊/自摸統計、對局重點。
- 本機資料：預設儲存在裝置內。
- 多人同步：你主動建立或加入房間時，房間、座位和牌局資料會經 Firebase 同步；完場後可封存到各自裝置。

## Privacy Short Notes
- 不需要註冊帳號；多人同步使用 Firebase 匿名驗證。
- 單人牌局與設定只儲存在裝置內；多人房間資料只會在你主動建立或加入同步房間時上傳至 Firebase。
- 完場後，每位成員可先封存本機紀錄；全部成員完成後，房主可刪除雲端房間資料。
