# 隱私權政策（麻雀番埋嚟 / Mahjong Fan）

最後更新日期：2026-08-06

「麻雀番埋嚟（Mahjong Fan）」是一個香港四人麻雀牌局記錄與計分工具。  
本 App 支援本機記錄及可選的多人同步，讓你在自己的裝置上記錄牌局、查看統計，或與同枱玩家同步牌局。

## 1. 我們收集哪些資料

本 App 不要求你提供姓名、電話、電郵、地址或位置等資料。不過，如你使用多人同步，我們會處理你主動提供或產生的下列資料：

- Firebase 匿名驗證產生的技術性使用者識別碼。
- 你在多人同步房間中使用的顯示名稱。本版本暫不提供設定或上傳頭像的功能。
- 房間名稱、房間代碼、規則、座位安排、牌局紀錄、分數及時間戳記。
- 不會追蹤你在其他 App 或網站上的行為。

請不要在玩家名稱、房間名稱或其他可輸入欄位填寫不必要的敏感個人資料。

## 2. 資料儲存方式

- 單人牌局、設定及封存紀錄會儲存在你的裝置本地，並可離線使用。
- 只有當你主動建立或加入多人同步房間時，相關房間資料才會儲存在 Firebase / Google Cloud Firestore，以供同枱裝置同步。
- 進行中的同步房間會保留，直至房主取消同步或結束牌局。邀請連結會在建立後約 2 小時失效。
- 完場後，各成員可把牌局封存到本機；所有成員完成封存後，只有房主可在 App 內刪除雲端房間、成員、座位及手牌資料。本機封存會保留至你在裝置內刪除。
- 本版本不會只因時間經過而自動刪除未被房主清理的雲端房間。一般玩家不能自行刪除整個雲端房間；如房主無法操作，可透過下方電郵查詢處理方法，並提供房間代碼及房主顯示名稱。

## 3. 網絡與第三方服務

- Firebase（Google）提供匿名驗證及多人同步所需的雲端資料服務。詳情請參閱 [Google 私隱權政策](https://policies.google.com/privacy)。
- 本 App 沒有內置廣告、analytics 或 tracking SDK。
- 本 App 不會出售你的資料，亦不會把資料用於廣告或跨 App／網站追蹤。

## 4. 權限

目前 iOS / Android 版本不要求敏感權限（例如通訊錄、相簿、位置等）作為基本功能前提。

## 5. 分享與備份

- 當你主動使用分享功能時，你選擇分享的內容會交由系統分享面板及你選取的服務處理。
- 如裝置啟用系統備份（例如 iCloud / Google Drive 裝置備份），屬於系統層級機制並由你自行控制。

## 6. 兒童與賭博聲明

- 本 App 為記錄與計分工具，不涉及真錢交易或真實賭博服務。
- 本 App 沒有向兒童作特別推廣。
